# Documentation Archive

Historical feature notes, implementation summaries, and bug-fix writeups.
Active docs stay at the repo root; see `README.md` / `START_HERE.md`.

## Layout

```
docs/archive/
├── completed-features/
│   ├── ai-training-plan/
│   ├── trainer-styles/
│   ├── training-plan-activation/
│   ├── hrv-tracking/
│   ├── mobile-calendar/
│   ├── analytics-tss/
│   ├── activity-detail/
│   ├── phases/
│   └── misc/
└── bug-fixes/
    ├── calendar/
    ├── tss/
    ├── date-range/
    └── hrv/
```

## Archive when

- Feature is stable / frozen
- Bug is fixed and verified
- Doc is “how we built it” rather than “how to use it”

## Keep at root when

- Setup / deploy / contributing
- Active backlog or project plan
- Current user-facing entry docs
