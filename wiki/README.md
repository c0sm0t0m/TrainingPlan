# How to Access the Kinesis Wiki

## 🚀 Quick Access

### Method 1: VS Code (Recommended)
1. Open the TrainingPlan workspace in VS Code
2. Navigate to **`wiki/Home.md`** in the Explorer
3. Press **Cmd+Shift+V** (Mac) or **Ctrl+Shift+V** (Windows) for rendered preview
4. Click links to navigate through the wiki

### Method 2: File System
1. Open Finder (Mac) or Explorer (Windows)
2. Navigate to: `/Users/boetthw3/Documents/99_Other/TrainingPlan/wiki/`
3. Double-click **`Home.md`** to open in your default markdown viewer

### Method 3: Command Line
```bash
# Navigate to wiki
cd /Users/boetthw3/Documents/99_Other/TrainingPlan/wiki

# Open in default app (macOS)
open Home.md

# Or view in terminal
cat Home.md
```

### Method 4: Web Browser (if using GitHub)
If this repository is hosted on GitHub, navigate to:
```
https://github.com/yourusername/TrainingPlan/wiki
```

GitHub automatically renders the `wiki/` folder as a navigable wiki interface.

## 📖 Documentation Organization

The wiki provides a **single entry point** for all project documentation:

### ✅ Organized by Topic
- **Getting Started**: Setup and installation
- **Features**: User-facing functionality
- **Technical**: Architecture and implementation
- **API Integrations**: External service integrations
- **UX Research**: Competitive analysis and design decisions

### ✅ No Duplication
- Most wiki pages **link to original documentation** (no file duplication)
- Original docs stay in their logical locations
- Wiki provides organized navigation structure

### ✅ Archived Old Docs
- Completed feature docs → `docs/archive/completed-features/`
- Fixed bugs → `docs/archive/bug-fixes/`
- Preserves history without cluttering active docs

## 🔍 Finding Information

### Search in VS Code
1. Press **Cmd+F** (Mac) or **Ctrl+F** (Windows)
2. Type your search term
3. Navigate through results

### Search Entire Workspace
1. Press **Cmd+Shift+F** (Mac) or **Ctrl+Shift+F** (Windows)
2. Type your search term
3. Searches all markdown files in the project

### Browse by Category
Start at [wiki/Home.md](Home.md) and navigate through sections.
