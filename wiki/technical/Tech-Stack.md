## Overview

Kinesis is built with:

### Backend
- **Python 3.11+** with **FastAPI** - Modern async web framework
- **PostgreSQL 15** with **TimescaleDB** - Time-series optimized database
- **Redis 7** - Caching and task queue
- **Celery** - Background job processing

### Frontend
- **React 18** with **TypeScript** - Type-safe UI framework
- **Vite** - Fast build tool with HMR
- **Material-UI v5** - Component library
- **Zustand** - Lightweight state management
- **Chart.js** - Data visualization
- **Leaflet** - Map integration

### Infrastructure
- **Docker Compose** - Container orchestration
- **Traefik** - Reverse proxy and SSL
- **QNAP NAS** - Deployment target
